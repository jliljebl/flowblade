Bins

In Flowblade a Bin is a named set of Media Items.

At least one Bin must exist at all times.

Adding a Bin

  1. Press Right Mouse in the Bins panel to launch a popup menu and select Add Bin.
  2. Or select Project > Bins > Add Bin from application menu.

Deleting a Bin

  1. Press Right Mouse in the Bins panel to launch a popup menu and select Delete Bin.
  2. Or select Project > Bins > Delete Bin from application menu.

Renaming a Bin

Click on the Bin name, type new name and press Enter.

Moving files to another Bin

  • Select and drag files on top of the Bin you wish to move the files into.
  • Select files and open Hamburger menu in Media panel and select menu item Move Selected media to Bin and then the menu item with the Bins name.

Filtering Bin View

Bins can be made to display only subset of media items they contain. Press on Filtering button in Media Panel bottom row next to hamburger menu and Columns buttons.

  • Filtering by media type. Select one of options All Files, Video Files, Audio Files, Graphics Files, Image Sequences, Pattern Producers, Unused Files.
  • Filtering by ratings. Select one of options in submenu Ratings Filtering, either Show All Ratings, Show Favorites, Hide Bad.

Each media item can be given a rating,

  1. Press Right Mouse on Media Item and select option in submenu Rating, either Unrated, Favourite or Bad.
