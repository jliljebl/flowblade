Monitor and Preview

Monitor Controls

  1. Press Right Mouse on Media Item and select menu item Transcode Media.. from popup menu.
  2. Transcode Media Window will open with Action, Encoding and Save Location panels.
    • Action panel has Action After Transcode drop down menu with two otions:
      • Create New Media Item Creates a new Media Item and leaves Media Item used to request transcode as is.
      • Replace Media In Project Replaces Media Item used to request transcode and all clips in Project created from it.
    • Encoding panel has Transcode Encoding drop down menu that allows for selection encoding for the created clip. Note that all transcoded media will be created using Project Profile properties such as screen dimensions, fps, colorspace etc.
    • Save Location panel has two widgets.
      • File Folder drop down menu has two options:
        • Project Data Store Transcoded file in saved in project's Data Store.
        • External Folder Transcoded file is saved in a user defined folder.
      • External Folder button activates if corresponding drop down menu selection is active and allows selecting the directory the transcoded file is saved in.
  3. Press Transcode button to launch a transcode rendering job shown in Jobs panel.
