Transcoding

Transcoding is converting a digital media item from one encoding to another.

Within the context of video editing the reason for doing this is usually to have media with more suitable colorspace or screen dimensions, or to have a media item with better playback performace e.g. by converting a frame sequence to a video clip, or converting to encoding supported by hardware decoding available in the system.

Transcoding Media Items

  1. Press Right Mouse on Media Item and select menu item Transcode Media.. from popup menu.
  2. Transcode Media Window will open with Action, Encoding and Save Location panels.
    • Action panel has Action After Transcode drop down menu with two otions:
      • Create New Media Item Creates a new Media Item and leaves Media Item used to request transcode as is.
      • Replace Media In Project Replaces Media Item used to request transcode and all clips in Project created from it.
    • Encoding panel has Transcode Encoding drop down menu that allows for selection encoding for the created clip. Note that all transcoded media will be created using Project Profile properties such as screen dimensions, fps, colorspace etc.
    • Save Location panel has two widgets.
      • File Folder drop down menu has two options:
        • Project Data Store Transcoded file in saved in project's Data Store.
        • External Folder Transcoded file is saved in a user defined folder.
      • External Folder button activates if corresponding drop down menu selection is active and allows selecting the directory the transcoded file is saved in.
  3. Press Transcode button to launch a transcode rendering job shown in Jobs panel.

Transcoding Media on Load

With Flowblade you can transcode all possible media on load or set only certain certain types of media to be transcoded on load.

  1. Select menu item Project->Transcode Settings to open the settings dialog.
  2. In Media Add Action panel select option from drop down menu.
    • No Action No action is taken on media load.
    • Suggest Transcode For Selected Depending on selection below transcoding is performed on load for files of type:
      • Variable Frame Rate Video.
      • Image Sequence Media
      • Interlaced Video
    • Transcode All Possible Transcdoes all video and image sequence media clips.
  3. Press Close to make current settings selections active.

Setting Default Transcoding Encoding

  1. Select menu item Project->Transcode Settings to open the settings dialog.
  2. In Default Transcode Encoding panel select option from drop down menu.
    • H.264 Preset Ultrafast
    • MPEG 4 Preset Ultrafast
  3. Press Close to make current settings selections active.
