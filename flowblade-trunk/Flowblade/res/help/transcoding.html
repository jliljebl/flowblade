Transcoding

Transcoding is converting a digital media item from one encoding to another.

Within the context of video editing the reason for doing this is usually to have media with more suitable colorspace or screen dimensions, or to have a media item with better playback performace e.g. by converting a frame sequence to a video clip.

Transcoding Media Items

  1. Press Right Mouse on Media Item and select menu item Transcode Media.. from popup menu.
  2. Transcode Media Window will open. displaying information on file path of render file, estimated time left, render time and a Progress bar widget.
    • Action drop down menu has two otions:
      • Create New Media Item Creates a new Media Item and leaves Media Item used to request transcode as is.
      • Replace Media In Project Replaces Media Item used to request transcode and all clips in Project created from it.
    • Encoding drop down menu allows for selection encoding for the created clip. Note that all transcoded media will be created using Project Profile properties such as screen dimensions, fps, colorspace etc.
    • Save Location
      • Create New Media Item Creates a new Media Item and leaves Media Item used to request transcode as is.
      • Replace Media In Project Replaces Media Item used to request transcode and all clips in Project created from it.
  3. Press Transcode button to launch a transcode rendering job shown in Jobs panel.
