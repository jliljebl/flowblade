Working with Projects

Flowblade Movie Editor saves work in Project files.

Project Contents

A Project contains:

  • A Project Profile determining video preview and output parameters, see below.
  • One or more Sequences of edited media
  • A collection of Media Files stored in Bins.
  • Rendered media, rendered data items and thumbnails stored in Data Store, see chapter: Data Stores.

Project Profile

Project Profile is the main data item selected to define video playback and export properties of a Project. Project Profile determines:

  • Frame rate.
  • Image Dimensions.
  • Image size in pixels.
  • Pixel aspect ratio.
  • Colorspace.
For best possible quality the input material, Project Profile and Rendering Profile should all have the same pixel dimensions and pixel aspect ratio.

Creating a New Project

  1. Open the Project creation dialog:
    • Application menu: Select File > New.
    • Keyboard shortcut: Press Control + N.
  2. Dialog allows setting two parameters for the new project:

    • Tracks count.

      Select the default number of video and audio tracks that are used for all new Sequences in project. Sequence track count can be changed later.

    • Data Store location is also selected on project creation.

      Data Store contains thumbnails, Generator and Rendered Transitions, stabilizing and motion tracking data, proxy files etc. used in the Project. See chapter: Data Stores.

  3. Remember always to save Project before closing the application or all work and data created during the editing session will be lost.

Project Actions

Changing Project Profile

  1. Select Project > Change Project Profile...from application menu. A dialog window opens.
  2. Select new Profile and save a version of the Project with the changes Profile.
  3. Open the created Project file and continue working.

Recreate Media Icons

  1. Select Project > Recreate Media Icons...from application menu.
  2. Wait for the icons creation operation to complete.
