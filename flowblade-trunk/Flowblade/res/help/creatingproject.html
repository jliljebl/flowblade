Creating New Project

Flowblade Movie Editor saves work in project files.

To create a new Project:

  • Menu: Select File > New from menu.
  • Keyboard Shortcut: Press Control + N.

A project contains:

  • One or more Sequences of edited media
  • A collection of Media Files stored in Bins.
  • Rendered media and thumbnails stored in Data Store.

There are two parameters that can be selected for a new project:

  • Project Profile Project Profile determines:
    • Frame rate.
    • Image Dimensions.
    • Image size in pixels.
    • Pixel aspect ratio.
    • Colorspace.
    Tracks count Select the deafult number of video and audio tracks that are used for all new Sequences in project. Sequence track count can be changed later.
For best possible quality the input material, Project Profile and Rendering Profile should all have the same pixel dimensions and pixel aspect ratio.

Data Store location is selected on project creation.

Data Store contains thumbnails, Generator and Rendered Transitions, stabilizing and motion tracking data, proxy files etc. used in the Project. See chapter: Data Stores.
