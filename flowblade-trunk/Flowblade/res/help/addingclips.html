Adding clips to Sequence

Drag'n'Drop

  1. Inititing drag by pressing with Left Mouse on:
    • A Media Item in Media Panel.
    • Monitor area when Source Clip is displayed on Monitor.
    • A Range Log Item row in Range Log panel.
  2. A clip icon appears under cursor as drag is initiated.
  3. Continue drag into Timeline area. A positioning indicator will appear on drop target Track.
    • A red line with small down pointing triangle indicates that an overwrite will be performed on all blank frames after the indicator.
    • A yellow line with small left pointing triangle indicates that an insert will be performed between two clips.
    • A red box around a clip indicates a clip replace will be performed on that clip. This indicator appears when cursor is placed near the middle of the replace target clip.
  4. Release Left Mouse to perform the indicated edit.
    • For Media Item and Monitor drags the range of added media will be the set Clip Range if that has been set, see chapter Monitor.
    • For Range Log Item the range of added media will be the set range.

Configuring Drag'n'Drop

  1. Select Edit > Preferences from application menu.
  2. In Editing panel select option from Drag-and-Drop Action drop down menu:
    • Always overwrite Blanks Does overwrite when targeted on empty and insert when targeted on clip on all Tracks.
    • Overwrite blanks on non-V1 tracks' Does insert always on Track V1 and on other tracks does overwrite when targeted on empty and insert when targeted on clip.
    • 'Always Insert' Always does insert on all Tracks.
  3. Clip replace will always be performed if draop is atrgeted on the ecnter of a clip.
