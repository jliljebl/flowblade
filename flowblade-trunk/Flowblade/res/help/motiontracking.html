Motion Tracking

When creating a motion tracking effect, we usually work with two image sources: one containing the image element to be tracked, and another containing the image that will follow the tracked element.

When using motion tracking to create a filter mask, the clip used as the tracking data source and the clip to which the mask is applied are usually the same.

Flowblade implements motion tracking using two filters and one filter mask:

  • Motion Tracking Create This filter creates tracking data based on an image region and the algorithm selected by the user.
  • Motion Tracking Apply This filter applies tracking data to another image, making it follow the image element from which the tracking data was created.

Motion-tracked masked filtering uses Filter Mask: Alpha Shape Motion Tracked, see below.

Filter: Motion Tracking Create

Add this filter to the clip containing the image element you want to track.

Parameters

Rectangle GUI Editor Position the red rectangle over the image element you want to track.

Tracking always starts from the first frame of the clip. Use this frame to position the rectangle.

If you want tracking to start in the middle of a clip, cut the clip at that point to create a new clip whose first frame is the desired tracking start point.

Keyframe Step Sets the interval, in frames, between keyframes in the generated tracking data. For example, a value of 5 creates a keyframe every 5 frames.

Algorithm Algorithm used to create the tracking data.

  • KCF - Kernelized Correlation Filters Offers better accuracy and speed than MIL. It also detects tracking failures more reliably than MIL. Does not recover from full occlusion.
  • MIL - Multiple Instance Learning Provides good tracking performance and can handle partial occlusion. However, tracking failures are not reported reliably. Does not recover from full occlusion.
  • MEDIANFLOW Reports tracking failures very reliably. Works well when motion is predictable and there is no occlusion, but fails when the tracked object moves too far between frames.
  • MOSSE - Minimum Output Sum of Squared Error Is robust to variations in lighting, scale, pose, and non-rigid deformations. It can also detect occlusion and pause tracking until the object reappears, then resume tracking.
  • CSRT Often provides better accuracy and resistance to overlap from other objects than the other algorithms. However, it is relatively slow and can behave unstably when the tracked object is lost.

Create Motion Tracking Data Pressing this button creates motion tracking data using the name entered in the text entry box above. Once created, the data can be used with the Motion Tracking Apply filter or the Filter Mask: Alpha Shape Motion Tracked.

Workflow

  1. Make sure the playhead is on the first frame of the tracked clip.
  2. Position the red rectangle over the image element to be tracked.
  3. Set the parameters and give the tracking data an identifying name.
  4. Press Create Motion Tracking Data and wait for the tracking data generation to complete.
  5. Check the results by moving the playhead through the clip.
  6. Press the Clear Data button if you want to try again with different parameters or a different tracking area.

Filter: Motion Tracking Apply

Add this filter to the clip containing the image you want to make follow the tracked image element.

Place the clip containing the image to be tracked on a track above the clip containing the tracked image element. Apply cropping if necessary.

Parameters

Select Motion Tracking Data Select the tracking data created for the image element you want to track.

Tracking always starts from the first frame of the clip.

If you want tracking to start in the middle of a clip, cut the clip at that point to create a new clip whose first frame is the desired tracking start point.

Tracking Coords Interpretation

  • Absolute Aligns the top-left corner of the image with the top-left corner of the tracking data box.
  • Top Left Justified Aligns the top-left corner of the image with the top-left corner of the screen in the first frame of tracking. Subsequent image movement is then determined by the relative movement recorded in the tracking data. This is useful, for example, when applying tracking data to text created in Titler. The text retains its initial position while following the movement recorded in the tracking data.

X Offset Moves the image horizontally relative to the position defined by the tracking data.

Y Offset Moves the image vertically relative to the position defined by the tracking data.

Size When set to Scale To Box, the image is scaled to fit the box defined by the tracking data.

Apply Motion Tracking Data Applies the selected tracking data to control the movement of the clip image, using the specified parameters.

Workflow

  1. Use the Select Motion Tracking Data dropdown menu to select which tracking data to apply.
  2. Set the parameters to fine-tune the tracked motion.
  3. Press the Apply Motion Tracking Data button to make the clip image follow the tracked motion.
  4. If necessary, change the parameters and press the Apply Motion Tracking Data button again to apply the modified motion.

Filter Mask: Alpha Shape Motion Tracked

Add this filter mask to the clip containing the image element to which you want to apply the filter.

A typical use is blurring a person's face to make them unrecognizable.

Parameters

Select Motion Tracking Data Select the tracking data created for the image element you want to track.

Tracking always starts from the first frame of the clip.

If you want tracking to start in the middle of a clip, cut the clip at that point to create a new clip whose first frame is the desired tracking start point.

X Offset Moves the filtered area horizontally relative to the position defined by the tracking data.

Y Offset Moves the filtered area vertically relative to the position defined by the tracking data.

Scale Adjusts the size of the filtered area.

Apply Motion Tracking Data Applies the selected tracking data to control the position and movement of the filter mask, using the specified parameters.

Workflow

  1. See above how to add a filter mask. Select the Alpha Shape Motion Tracked filter mask.
  2. Set the mask parameters.
  3. Press Apply Motion Tracking Data to create a motion-tracked filter mask.
