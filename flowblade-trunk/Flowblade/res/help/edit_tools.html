Timeline Edit Tools

Flowblade Movie Editor has 6 edit tools for doing timeline edits.

Selecting Tools

Use Tool Switcher button drop menu or press key 1 - 6 to pick a tool.

It is also possible to use Tool Dock instead of Tool Switcher button by selecting Dock in View->Edit Tool Selection Widget.

Use keyboard shortcuts! Press 1–6 to quickly switch tools. The shortcuts work when the timeline has keyboard focus. Click the timeline to give it keyboard focus.

Tools

Move

Move one or more clips to another position on the Timeline and overwrite material at the destination

  1. Select a clip.
    • Click Left Mouse on a clip.
  2. Select the other end of the clip range if moving multiple clips.
    • Click Ctrl + Left Mouse on the clip you wish to use as the other end of the clip range.
  3. Drag the clip(s) to a new position.
    • Press Left Mouse on a selected clip and drag the clip(s) to a new position.
    • Red shadow clips show the overwrite area.
    • You can also move clips to a different track.

Drag clip ends to change the clip length.

  1. Place the cursor near the clip end.
    • When the cursor changes to a horizontal arrow with a vertical bar, you can start a clip-end drag edit.
  2. Drag the clip end with the Left Mouse.
    • Increasing the clip length performs an overwrite on blank or empty space.
    • Increasing the clip length performs an insert when there are other clips at the destination.
    • Decreasing the clip length performs a splice-out.
  3. Drag the clip end with Ctrl + Left Mouse.
    • Increasing the clip length performs an overwrite on all clips up to the length of the adjacent clip.
    • Decreasing the clip length adds material back from the adjacent clip, as much as possible.

Select and overwrite move all Timeline items contained in a box selection.

  1. Select an area on Timeline by dragging a box selection with Left Mouse around all items you wish to move and release mouse button.
  2. Press Left Mouse inside the box selection and drag the box into new position on timeline and release.
  3. The box contents overwrite material at the new position, and Compositors are moved.

Dual Sync Trimming

  1. Check option Auto Sync Trim Single Childs
  2. When doing Clip End Drag Child Clip follows the legth change if it has enough media to do that.
  3. If Child Clip does not have enough media to apply the same edit it will remain unaffected.

Insert

Splice out one or more clips and insert them at desired cut on any track.

  1. Select clip
    • Click Left Mouse on a clip.
  2. Select other end of clip range if moving multiple clips
    • Click CTRL+Left Mouse on the clip you wish to be the other end of move clip range.
  3. Drag Clip(s) to new position
    • Press Left Mouse on a selected clip and drag clip(s) to a new position.
    • Yellow arrow displays insert point.
    • You can also move clips to a different track.

Drag clip ends to change clip length.

  1. Place cursor near clip end.
    • When cursor changes to horizontal arrow with vertical bar you can start clip end drag edit.
  2. Drag clip end with Left Mouse.
    • Increasing the clip length performs an overwrite on blank or empty space.
    • Increasing the clip length performs an insert when there are other clips at the destination.
    • Decreasing the clip length performs a splice-out.

Spacer

Move all Timeline items after pressed frame on all tracks or on a single track

  1. Select a clip on Timeline and move it and all items to the right of it
    • Press Left Mouse on a clip.
    • Continue dragging the clip and all clips and Compositors to its right to a new position.
    • It is not possible to move items over existing clips. Items can only be moved into empty space.
  2. Use Control button to only affect items on a single track
    • Press Control and use Left Mouse to move all items on single track to the right of the selected clip

Multitrim

Do Trim, Roll or Slip edits based on cursor position on timeline.

  • Roll edit moves edit point between two clips so that their combined length stays the same.
  • Slip edit changes the displayed area of media in a clip while keeping the clip position unchanged on the timeline.
  • Trim edit makes clip longer or shorter from either clip's end or from clip's beginning.

  1. Cursor change indicates which type of trim edit is done when edit is initiated with Left Mouse press.
    • If cursor is positioned directly on the cut, a Roll edit is done.
    • If cursor is positioned on the center of clip, a Slip edit is done.
    • On other cursor positions a Trim edit on the closer clip end is done.
  2. Continue on to Left drag to complete the edit.

Ripple Trim

  1. Position cursor near clip end and keep Alt key down when pressing Left Mouse to start a Ripple Trim edit.
  2. Continue on to Left drag to complete the edit.
  3. The range of a Ripple Trim edit is limited so that clips on other tracks cannot be overlapped.

Keyboard Trimming

  1. Position the cursor to select the trim you wish to perform.
  2. Press the Enter key to start the keyboard edit.
  3. Use the Left Arrow or Right Arrow key to move the edit point. Hold the Ctrl key to move 10 frames with each arrow key press.
  4. Press Enter to complete the keyboard edit.

Dual Sync Trimming

  1. Check option Auto Sync Trim Single Childs.
  2. When doing a trim Trim Child Clip follows trim if it has enough media to apply the same trim.
  3. If Child Clip does not have enough media to apply the same trim it will remain unaffected.

Cut

Cut single or multiple clips.

  1. Cut a single clip.
    • Position the cursor on the frame where you want to make the cut and press Left Mouse.
  2. Cut clips on all tracks at the selected position.
    • Position the cursor on the frame where you want to make the cut and press Ctrl + Left Mouse.

Keyframe

Edit Volume or Brightness filter keyfrmes on timeline.

  1. Click on the clip you wish to edit.
    • A Volume filter is created automatically if clip does not have one.
    • A keyframe editor overlay is displayed on timeline.
  2. Press and drag keyframe with Left Mouse to set its value and position
  3. Press on empty on overlay area with Left Mouse to create and drag keyframe.
  4. Delete key deletes the active keyframe.
  5. Press on Hamburger menu icon to change to Brightness keyframe editing or to access additional edit actions.
  6. Press outside overlay area to close overlay editor.
